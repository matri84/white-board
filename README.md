## تخته وایت برد
این برنامه یک تخته وایت برد است که شما می‌توانید با آن هر چیزی که در ذهن دارید را رسم کنید.

این برنام همچنین دارای قابلیت های زیر است:
* تغییر رنگ قلم
* تغییر اندازه قلم
* ذخیره کردن تخته به صورت عکس

  شما می‌توانید به سادگی از این برنامه برای تدریس، جزوه برداری و یا هر مورد دیگری که می‌خواهید استفاده کنید.

 شمایی که برنامه نویس و توسعه دهنده برنامه‌های تحت وب هستید. می‌توانید این پروژه را توسعه دهید و امکاناتی بیشتر به آن استفاده کنید.

 من محمد عطری توسعه دهنده فول استک در حوزه وب امیدوارم شما از این برنامه به خوبی استفاده کنید.
